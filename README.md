# 🗡️ 大庚剑阵 — 御剑飞行

> 沉浸式 3D 飞剑交互体验 · 手势驱动 · 剑阵变换

一个基于 **Three.js** 3D 渲染和 **MediaPipe** 手部追踪技术的 Web 交互应用。通过摄像头识别手势，实时控制数百把飞剑组成不同的剑阵形态，体验御剑飞行的沉浸感。

---

## ✨ 效果展示

- **500 把飞剑**同时渲染，每把剑带有独立的颜色渐变（青玉 → 冰蓝 → 金色）
- 粒子拖尾系统、能量网络、光柱、冲击波等视觉特效
- 剑阵切换时带有平滑过渡动画
- 支持鼠标模拟操作（无摄像头时可用）

## 🎮 剑阵模式

| 模式 | 手势 | 键盘快捷键 | 描述 |
|------|------|-----------|------|
| **剑阵归位** | ✊ 握拳 | `2` | 飞剑环绕成球状，缓缓旋转，阵眼发光 |
| **御剑飞行** | ☝️ 食指 | `1` | 飞剑跟随手势方向飞行，剑身随速度变色 |
| **天女散剑** | 🖐️ 五指张开 | `3` | 飞剑四散，布满整个空间 |
| **大庚剑阵** | ✌️ 二指（V字） | `4` | 五环剑阵层叠旋转，中央升起光柱 |
| **无极剑涡** | 🤟 三指 | `5` | 飞剑形成螺旋涡流状，如黑洞旋转 |
| **万剑归宗** | 🖖 四指 | `6` | 飞剑凝聚成巨大剑形，震撼集结 |

> 💡 **提示**：切换模式时触发冲击波特效，带来视觉反馈。

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| **Three.js** | 3D 场景渲染、飞剑建模、粒子系统 |
| **MediaPipe Hands** | 实时手部关键点追踪与手势识别 |
| **EffectComposer / UnrealBloomPass** | 泛光（Bloom）后期特效 |
| **WebGL** | GPU 硬件加速渲染 |
| **WebRTC (getUserMedia)** | 摄像头视频流获取 |
| **ShaderMaterial** | 自定义着色器实现粒子拖尾效果 |

## 🚀 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/baoshengzheng/sword.git
cd Flying-Sword-Formation
```

### 2. 直接运行

用浏览器直接打开 `index.html` 文件即可。

> 推荐使用 Chrome / Edge 最新版本，确保支持 WebGL 和摄像头访问。

### 3. 权限设置

页面会请求摄像头权限，请点击 **允许**。如无摄像头，可使用**鼠标移动**模拟手势方向，**键盘数字键（1-6）** 切换模式。

### 飞剑（FlyingSword）

- 每把飞剑是独立的 3D 模型（剑身 + 护手 + 剑穗 + 剑柄）
- 支持**群体智能**行为：分离、对齐、聚集（类 Boids 算法）
- 飞行模式下跟随手势方向，速度越快剑身越亮
- 每个剑阵模式有独立的数学模型（球面坐标、涡旋参数、环状排列等）

### 手势识别

MediaPipe 识别手部 21 个关键点后，通过指尖和指节的位置关系判断手势：

- **伸出的手指数量**（0-5 根）决定模式
- **掌心位置**映射到 3D 空间坐标
- **指尖方向**控制飞剑飞行方向
