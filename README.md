# 剑阵飞行 (Flying Sword Formation)
剑阵飞行 是一个基于 Web 技术的飞剑控制游戏，用户通过手势识别来控制虚拟飞剑的动作，项目结合了 three.js 实现的 3D 渲染和 MediaPipe 提供的手势追踪技术。玩家可以体验不同的剑阵模式，如飞剑飞行、剑阵归位、天女散剑等。

## 项目简介

**剑阵飞行** 是一个基于 Web 技术的飞剑控制游戏，用户通过手势识别来控制虚拟飞剑的动作。项目结合了 `three.js` 实现的 3D 渲染和 `MediaPipe` 提供的手势追踪技术，用户可以体验不同的剑阵模式，如飞剑飞行、剑阵归位、天女散剑等。

## 特性
- 基于手势识别，支持多种剑阵模式。
- 使用 `three.js` 实现飞剑的 3D 渲染和动画。
- 支持实时手势识别与视觉效果。
- 界面支持自适应窗口大小，动态调整 3D 视图和手势控制。

## 技术栈
- `three.js`: 用于 3D 渲染。
- `MediaPipe`: 用于手势识别和实时手部追踪。
- HTML5, CSS3: 实现基本的页面结构与样式。
- JavaScript (ES6): 实现前端逻辑和交互。

## 安装与运行

### 1. 克隆项目
首先将本项目克隆到本地：

```bash
git clone https://github.com/your-username/剑阵飞行.git
cd 剑阵飞行
```

### 2. 打开项目

直接打开 `index.html` 文件，使用浏览器查看效果。请确保浏览器支持 WebGL 和摄像头访问。

### 3. 权限设置

为了启用手势识别，项目需要访问摄像头。在浏览器中访问时，记得允许摄像头权限。

## 使用说明

- **一指**: 食指伸出，触发“御剑飞行”模式，飞剑在空中飞行。
- **握拳**: 切换到“剑阵归位”模式，飞剑回归初始位置。
- **五指张开**: 激活“天女散剑”模式，飞剑四散飞行。
- **三指**: 食指、中指、无名指或食指、中指、小指一起伸出，触发“大庚剑阵”模式，剑阵呈现特殊效果。
